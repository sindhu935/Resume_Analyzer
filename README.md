# Resume Analyzer

A responsive Resume Analyzer web application that helps evaluate resumes based on predefined criteria such as skills, education, experience, and formatting. The project is designed to simplify resume screening and provide quick insights for users.

## Features
- Upload and analyze resumes
- Resume score evaluation
- Skill and keyword checking
- Clean and responsive UI
- Easy-to-use interface

## Technologies Used
- HTML
- CSS
- JavaScript
